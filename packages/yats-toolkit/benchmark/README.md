# YATS Benchmark

Measures how many tokens YATS saves when an AI agent answers questions about a codebase.

## What it measures

For each question, the agent answers twice on a fresh LLM context:

| | Tools available |
|---|---|
| **Without YATS** | `read_file`, `grep` — reads source files directly |
| **With YATS** | `search_code`, `find_symbol`, `find_callers`, etc. — queries knowledge graph |

Metrics collected:
- **Time**: how long the agent took to answer
- **Input tokens**: tokens sent to the LLM
- **Output tokens**: tokens generated by the LLM
- **Savings**: percentage of tokens saved with YATS vs without

## How to run

```bash
# 1. Make sure YATS is running
yats status

# 2. Run the wizard
./run.sh
```

The wizard will:
1. Let you pick an agent (Cursor, Claude CLI, Codex)
2. Pick a language and repo (auto-cloned + indexed if needed)
3. Pick which questions to run
4. Run each question, measure everything
5. Show a results table
6. Save to `results/`

## Results format

```json
{
  "agent": "cursor",
  "repo": "fastapi/fastapi",
  "language": "python",
  "questions": [
    {
      "name": "01-middleware",
      "without_yats": { "time_ms": 4500, "input_tokens": 8200, "output_tokens": 350 },
      "with_yats":    { "time_ms": 1200, "input_tokens": 800,  "output_tokens": 280 },
      "savings_pct": 89
    }
  ]
}
```
